## 1. Motivation / 动机

**为什么建这个数据集。** 大多汉字 NLP 评测把字当作 token 序列中的原子单位；汉字字谜迫使模型把一个字当作**可分解、可重组的结构化对象**并逆向搜索。答案恰为一个汉字、判分精确、字形操作离散可核查，因此适合作为**行为层结构探针**的载体。注意本数据集不是要测「谁更聪明」，而是要回答一个可判定的方法论问题：字谜的读数能否归因于目标能力，而非题目分布或评测协议本身。

**术语边界。** 本文的「结构探针」是**行为层探针（behavioral probe）**，与 Hewitt & Manning (2019) 以内部表征为输入、检验句法树距离是否被线性编码的 *structural probe* 不同。本数据集**不探测隐藏状态、不声称能力定位到特定层或神经元**，只借用 control task / selectivity 的方法论要求。

**资助与利益冲突。** 由发布机构自建，无外部资助，无已知利益冲突。所有模型调用按 API 付费发生，未与任何模型供应商有合作或背书关系。

## 2. Composition / 组成

**一个实例代表什么。** 一行 JSON 记录一条谜面（自然语言线索）、它的单一汉字谜底、以及相应的结构卡 / 解释 / 溯源 / 答题结果。共 5 类实例：参考谜面、模型创作谜面、质检判定、闭环答题记录、ICL 调用记录。逐文件字段见 `data/README.md`。

| 子集 | 实例数 | 是否含第三方内容 |
|---|---|---|
| 参考谜面 | 1,019 | 是，CC-Riddle 派生 |
| 参考谜面（下架） | 31 | 是，网络 UGC；**不在包内**，见 `data/WITHHELD.md` |
| 模型创作谜面 | 600 | 否（模型生成，标 `no_url`） |
| 质检判定 | 600 | 否 |
| 闭环答题 `cross` / `self` | 597 + 597 | 否 |
| ICL 调用 | 192 | 否 |
| 目标汉字 | 100 | 现代汉语高频简化字 |

**是否有缺失信息。** 有，且刻意保留为空而非填补：字义字段未引入（项目决定不引入第三方字典释义）；IDS 含占位符或不可拆的字，其 `ids` 不作权威字理；部分 `reasoning` 为空串（模型未输出推理）；`predicted_answer` 在异常调用中可能为非单字，一律记 `correct=0` 并留 `format_bad / error` 标记。

**是否含机密 / 个人数据。** 不含。无人类被试、无个人信息、无明文凭据。所有时间戳为 API 调用时间（UTC+8）。

**子集之间的关系。** `generated-*` → `quality` → `blind` / `blind-self` 通过 `gid` 逐条连接；`reference-slice` → `explanations-llm` / `provenance-reference` 通过 `rid` 连接；`icl-probe-items` → `icl-probe` 通过 `gid` 连接。**`cross` 与 `self` 是同一批 597 题的逐题配对**，这是全部统计推断的基础，不可打散。

**是否存在重复 / 冗余。** 参考谜面按谜底字成簇（这是上游语料的固有性质，也是我们诊断公开切片无排名效度的依据）；31 条网络素材中有 12 条与 CC-Riddle 转载链直接重复，已在采集时剔除，未进入 1,019。创作题通过 3-gram Jaccard ≤ 0.35 检查排除改写参考谜面，但该阈值**未经人工验证**。

## 3. Collection Process / 采集流程

| 阶段 | 日期 | 动作 |
|---|---|---|
| 上游语料 | 2022–2023 | CC-Riddle 公开 27,517 条（网络爬取 + 模型生成 + 人工筛选），CC BY-NC-SA 4.0 |
| 目标字表 | 2026-11-04 | 取 100 个高频简化字，附字表、IDS、笔画、部首、频率序 |
| 参考切片 | 2026-11-05 | 从上游取 1,019 条人工谜面；按字定向补缺 31 条网络谜面；共 1,050 条 |
| 解释生成 | 2026-11-05 | 1,023 条 LLM 解释（给定谜面+谜底）+ 27 条站点现成提示 |
| 谜面创作 | 2026-11-05 | 两个模型各 300 条，指定手法 + 4 条跨字示例 + 目标字结构卡 |
| 质检 | 2026-11-05 | 600 → 597；泄底 0、长度违规 0 |
| 交叉盲测 | 2026-11-05 | 597 题，A 制谜 → B 作答 |
| 同题自测 | 2026-11-06 | 597 题，隔天独立进程、全新单轮对话、无历史 / 无谜底 / 无 reasoning |
| ICL 探针 | 2026-11-06 | 24 题 × 4 条件 × 2 模型 = 192 次，零失败 |
| 论文 1 | 2026-11-06 | 中文原稿；2026-11-09 英文全译 |
| 公开导出 | 2026-11-09 | 方案 C：过滤 31 条 UGC，生成 v0.1 |
| 论文 2 | 2026-11-06 / 11-10 | 另一课题组的中文原文；2026-11-10 英文全译（仅文档层新增，数据零改动） |

**谁采集、谁标注。** 由发布机构用脚本自动采集与生成；**没有人工标注员**，没有众包，没有人工谜面质量 / 谜底唯一性评审。这是本数据集当前最大的质量缺口。

**采样机制。** 目标字按现代汉语频率序取前 100；参考谜面按谜底字定向选取（非随机抽样）；ICL 题集按 (制谜方 × 手法) 分层取 24 题，种子 `20261106` 并 SHA256 冻结；示例字 {对, 但, 和, 学} 与测试字严格隔离。定向选取意味着**参考子集不是上游语料的无偏样本**，不得据此估计上游分布。

## 4. Preprocessing / 预处理与标注

- 判分：答案去空白后与单一汉字精确匹配，无 LLM-as-judge、无评分量规、无偏好对。
- 归一：`split` 统一 `test`，原值保留在 `source_split`（**不可删**，公开集记忆污染诊断的关键协变量）。
- 异常：记 `correct=0` 且分母不变，另留 `format_bad / error / timed_out`，报告同时给「含异常」与「剔除异常」两个口径。
- 解释一律标注「非权威字理」；模型生成内容标 `no_url`，只记模型 / prompt 版本 / 时间戳 / 输入快照哈希。
- **原始记录保留**：所有 JSONL 保留模型原文（含错误推理、错误答案），不做纠错，以保证逐题可复核。
- 版本纪律：`prompt_version` 由 `data/pipeline_meta.json` 决定；改模板必须同步升版本，否则破坏 `skill_sha256` 溯源。

## 5. Uses / 用途

**推荐使用**

- 同一批题、同一判分器下，不同信息条件 / 不同 solver 之间的**配对诊断**（C1/C2/C6 满足）。
- 研究生成–求解不对称、程序性知识、自我熟悉效应、ICL 中推理内容正确性 vs 自写来源的作用。
- 复现配套论文的六条判据 C1–C6、2×2 全因子分解、四格诊断与全部统计。
- 作为「A 生成 → A 评估」型评测设计的**反例教材**：不交叉制谜方与评估方时，读数会被评估能力主效应污染。

**不推荐 / 明确反对**

- ❌ **用作模型能力排行榜 / 基准**。论文已裁定现有公开切片无排名效度。
- ❌ 把 ICL 结果当作训练有效性证据（所有 *p* ≥ 0.125，且无任何训练实验）。
- ❌ 把 1,023 条解释当作 CoT 监督信号或权威字理（58.9% 自评 `low`，事后合理化）。
- ❌ 商业用途（CC BY-NC-SA 4.0 的 NC 条款）。
- ❌ 把 `source_split` 删掉后做「记忆污染」诊断。

## 6. Distribution / 分发

以 GitHub 仓库形式公开发布，纯文本 UTF-8 / LF。许可证按目录分层：`data/` CC BY-NC-SA 4.0；`scripts/` MIT；`docs/`、`README*.md`、`paper/README.md` 与 Paper 1（`paper/riddle-paper*`）CC BY 4.0。**例外**：Paper 2（`paper/gmn-paper-zh.pdf`、`gmn-paper-en.*`）由另一课题组署名，原文未声明论文许可，不适用 `LICENSE-DOCS`，仅供对照阅读与学术引用。完整第三方署名与修改声明见 `THIRD_PARTY.md` 与 `paper/README.md`，再分发 `data/` 时须保留。

`manifest.json` 给出每个文件的字节数与 SHA256、行数口径、下架统计与项目版本；`scripts/verify_release.py` 可离线复算。仓库地址为 `https://github.com/SunSeeding/ccrp`，已回填 `CITATION.cff` 的 `repository-code` / `url`。

离线站点、小游戏、原始网页抓取、构建期 prompt 快照、备份与日志**不在 v0.1 内**，仍留在本地受限研究环境。

## 8. Ethical & Legal Considerations / 伦理与法务

1. **上游权利**：1,019 条参考谜面派生自 CC-Riddle（Fan Xu / Yunxiang Zhang / Xiaojun Wan，北京大学王选所），CC BY-NC-SA 4.0，仅允许非商业使用。本包保留署名、许可链接、原库 URI、行 id 与源文件 SHA256，并声明已做「选取、重排、补解释」的修改。
2. **下架的 31 条**：采集时自带「网络 UGC 转载，未取得明确授权；仅本地/受限研究使用」标记。公开仓库非受限环境，故按方案 C 不随包发布，仅保留 SHA256 指纹。**本地研究产物未删除**；权利人如需从本地研究集也移除，请提 issue。
3. **27 条站点现成解析**是这 31 条的子集，随之下架；`data/` 中的解释全部为模型生成（标 `no_url`）。
4. **民间口头传统**：许多短谜语属长期流传的民间文学，著作权归属难以确定；本包对这类内容采取保守姿态，不作权利主张。
5. **模型服务条款**：创作谜面与解释由商用 API 生成，发布前未逐条审阅各供应商对输出内容的条款；使用者应自行确认其使用场景。
6. **潜在误用**：最大风险是被当作排行榜基准或训练集。已在 README 首页、本卡片 §5、论文 §6.2 三处显式警示。
7. **隐私 / 凭据**：无人类被试数据；发布包经全库扫描，零明文凭据、零本机绝对路径、零第三方网页 URL。
8. **非 OSI 开源**：CC BY-NC-SA 4.0 不是 OSI 认证开源许可，请勿称本数据集为「开源数据集」。
