# 汉字字谜能否成为大语言模型的结构探针？

## ——基于生成–求解闭环、2×2 全因子与 ICL 控制任务的有效性裁定

**作者**：春芽数源（机构署名）　　**机构**：Spring Buds Data Source Inc.　　**日期**：2026-11-06　　**公开版**：2026-11-09（配套数据集 CCRP DataSet v0.1）

> **本文定位**：本文回答一个可判定的方法论问题——汉字字谜在何种条件下能作为大语言模型的结构探针。研究为 API 调用层面的零权重修改实验；**不包含任何训练、微调或梯度更新实验**，第 6.4 节关于「训练该补什么」的内容全部明确标注为假设。本文不报告模型能力排名。

## 摘要

汉字字谜要求把单字当作可分解、可重组的结构化对象并逆向搜索，答案恰为一个汉字、判分客观，因而常被当作检验大语言模型（LLM）汉字知识的任务。但它能否成为一支**结构探针**——即一个读数可归因于目标能力、而非题目分布或评测协议本身的工具——此前没有明确判据。本文先给出行为层结构探针的六条有效性判据（客观判分 C1、结构化可分解 C2、信息条件可控 C3、选择性与对照 C4、能力层可区分 C5、可复现可审计 C6），再用三套递进实验逐条检验：零样本解谜基线、**生成–求解闭环**（597 条自创谜题，由制谜方本人在相隔一天的全新单轮对话中作答）、**ICL 控制任务**（24 题 × 4 条件 × 2 模型 = 192 次调用，同批示例谜面仅替换 `assistant` 推理内容来源）。

主要结果：交叉盲测猜中率 39.0%（233/597），同题自测升至 44.2%（264/597），逐题配对 McNemar 精确检验 *p*=0.0144；但按制谜方分层出现方向相反的差异（kimi +21.5 pp，u2 −11.0 pp，均显著）。这是混淆而非矛盾：制谜方 × 猜题方恰好构成近似 2×2 全因子，可加分解给出猜题能力差 *β*=+16.26 pp、题源难度差 *α*=+11.36 pp 与**自我熟悉净效应** *γ*=+5.22 pp，后者在平衡设计下恒等于总体差值（实测 +5.19 pp，0.03 pp 差异来自 298/299 的组不平衡）；即两家模型共享同一个自我优势，表观符号被猜题能力差翻转。四格诊断进一步显示 273 条两方皆错、91 条仅自测对、60 条仅交叉对：模型在持有答案、字理卡与跨字示例时能写出合理的解谜叙述，撤去这些条件后却无法稳定逆向执行，呈现**生成–理解的程序性不对称**。两处不支持强解释的负面结果亦如实报告：仅自测对与仅交叉对的拆形占比差异 Fisher *p*=0.245；出题推理文本含谜底字的比例差异 *p*=0.066。

ICL 控制任务**无任何统计显著结果**（所有 McNemar *p*≥0.125），却提供一个干净的天然对照：kimi 自写的 4 条示例解释全部正确，其 `self` 条件与人工程序示例持平（45.8%）；u2 自写解释中有一条把「旭日初升」误拆为「旭去日＝九」，其 `self` 条件降至 20.8%，比零样本低 16.7 pp，`program` 对 `self` 配对为 4:0。据此，示例效果取决于推理内容**是否可执行且正确**，而非是否出自模型自身。

**综合裁定是有条件的肯定**：C1/C2/C6 完全满足；C3/C4 在自建闭环题集上满足、却被现成公开切片否决（100 题仅 11 个答案字、85 题来自公开 train/valid、test 15 题答案全为「旦」、四家推理预算不对等）；C5 只有方向性证据。因此字谜**能**作为诊断型结构探针，**不能**在现有题集上作为排名型基准，作为训练信号探针则**尚不能判定**。本文给出补齐 C3/C4/C5 的协议建议，并把训练价值严格限定为三条可证伪假设与三类已实证的数据风险。

**关键词**：汉字字谜；结构探针；大语言模型；控制任务；选择性；程序性知识；生成–求解不对称；自我偏好；上下文学习；评测效度

## 1 引言

### 1.1 字谜为什么有资格被当作结构探针

大多数中文 NLP 评测把汉字当作词元序列中的原子单位。汉字字谜却强制要求相反的操作：给定一个自然语言谜面，求解者须把目标字还原为部件、笔画、读音与义项的**组合结构**，并执行「取半、增删、并置、别解、谐音转调」等一系列可逆操作，最终收敛到唯一的一个汉字。以本文实验中的一条谜面为例：

> 「叉去一点，添上一寸」→ **对**（「叉」去一点得「又」，并置「寸」）

这一任务有三个对探针设计极为有利的性质。其一，**答案是单个汉字，判分为精确字符串匹配**，无需 LLM-as-judge、无需人工评分、无需主观量规，从而把「测量工具本身的偏差」压到最低。其二，**字形操作是离散且可验证的**，一条推理链要么确实能从谜面走到谜底，要么不能，可以逐条审计；且字形、语义、音韵三类线索可被正交地指定。其三，**生成与求解互为逆过程**：出题是从（字 + 字理 + 手法）到谜面，猜题是从谜面回到字，二者构成可控闭环，允许我们操纵「谁出题、谁猜、上下文里给什么」来分离能力成分。

CC-Riddle（Xu et al., 2022/2023）最早把这一任务系统化，构建了人工谜面与模型生成谜面混合的问答数据集，并报告 BERT、ChatGPT、ChatGLM 均表现不佳。近年的谜题推理评测（如 RiddleBench, Halder et al., 2025）进一步把谜题用作诊断工具，观察到幻觉级联、自我确认偏差与推理脆弱性。但已有工作大多沿用一个隐含前提：**把字谜当作一道题，用得分高低衡量模型**。若改问「字谜能否成为探针」，需要回答的就不是分数，而是：**这个读数究竟测到了目标能力，还是测到了题目分布、提示格式与评测协议？**

### 1.2 「探针」不等于「基准」：六条有效性判据

必须先澄清术语。probing 文献中的 *structural probe* 指以模型**内部表征**为输入、用线性变换检验句法树距离是否被编码（Hewitt & Manning, 2019）；本文的「结构探针」是**行为层探针（behavioral probe）**：用一个结构化、可判分、信息条件可控的**外部任务**去诊断模型能力。我们不对隐藏状态作任何探测，也不宣称定位到具体层或神经元。但表征层 probing 提出的方法论要求对行为层同样成立，甚至更为关键——Hewitt & Liang（2019）指出，探针必须配合**控制任务（control task）**才具**选择性（selectivity）**，否则高读数可能只是探针自身学会了任务；Belinkov（2022）系统梳理了基线、度量、分类器选择与相关性解释等方面的陷阱。

据此，本文把「字谜能否成为结构探针」拆成六条可判定的判据：

**表 1　行为层结构探针的六条有效性判据**

| 判据 | 要求 | 违反时的典型伪影 | 检验位置 |
|---|---|---|---|
| C1 客观可判分 | 答案唯一可验证，不依赖评判者或量规 | LLM-as-judge 自我偏好、评分漂移 | §3.2、§4.2 |
| C2 结构化可分解 | 任务可拆为正交的原子操作维度，以便定位缺口 | 只有一个总分，无法区分字形 / 语义 / 音韵 | §3.4、§4.3 |
| C3 信息条件可控 | 能构造「持有答案 / 不持有答案」的隔离对照，且题集无记忆污染 | 公开集泄漏、答案先验、按答案字聚集 | §3.3–3.4、§4.1 |
| C4 选择性（控制任务） | 得分变化可归因于目标能力，而非格式、示例风格、提示长度或猜题能力主效应 | 把 few-shot 格式效应、模型强弱差误读为能力 | §4.4、§5.1 |
| C5 能力层可区分 | 能区分「权重里已有、缺格式对齐」与「需权重层注入」 | 由单次准确率直接推断训练方案 | §5（仅方向性） |
| C6 可复现可审计 | 冻结题集、固定 prompt 版本、逐题留存、溯源分级 | 无法复算、无法排除伪造来源 | §5.4、附录 A |

六条判据构成一个判别框架：C1–C2 决定「有没有资格」；C3–C4 决定「读数是否可归因」，是探针与基准的分水岭；C5 决定「能否外推到训练」；C6 决定「结论能否被复核」。第 6.1 节将逐条给出裁定。

### 1.3 研究问题与贡献

把上述判据应用于字谜，得到三个可回答的经验问题：

- **RQ1（可逆性，对应 C2/C5）**：模型在持有答案与字理信息时写出的解谜叙述，是否对应一条在只给谜面时仍可执行的求解程序？若否，缺口位于「知识表征」还是「程序执行」？
- **RQ2（选择性，对应 C4）**：把同一批谜题交回制谜方本人（全新会话、不携带出题记忆），猜中率是否上升？该上升是「自己更懂自己的谜」，还是「谁更会猜」这一主效应造成的假象？能否在客观判分任务上把它量化并分离？
- **RQ3（可激活性，对应 C5）**：若不改动权重、只在上下文里给不同质量的解谜示例，哪些能力被激活、哪些纹丝不动？由此能否对「训练该补什么」提出可证伪的推断？

三套实验分别见第 3.3、4、5 节，综合裁定见第 6 节。本文贡献如下：

1. **提出行为层结构探针的六条判据并完成逐条裁定**。结论不是简单的「能 / 不能」，而是分场景的：诊断型成立、排名型在现有题集上不成立、训练信号型待定（表 16、表 17）。
2. **提出生成–求解闭环并完成 2×2 全因子分离**。597 条同题配对实验给出自我熟悉净效应 *γ*=+5.22 pp（配对 McNemar *p*=0.0144）；证明按制谜方分层时「方向相反」是猜题能力主效应 *β* 翻转符号所致。与已有 self-preference 研究（Zheng et al., 2023；Halder et al., 2025）多基于主观打分不同，本设定**判分完全客观、效应可加分解、且给出识别条件**。
3. **给出生成–理解不对称的四格证据与诚实的负面结果**。273 条两方皆错（会意+谐音占 79.9%，高于总体 67.0%）、91 条仅自测对、60 条仅交叉对，制谜方归属在两格间差异极显著（Fisher *p*=1.65×10⁻¹²）；同时报告两处**不支持**强解释的检验（*p*=0.245、*p*=0.066）。
4. **以「同谜面、仅换推理来源」的 ICL 控制任务给出监督质量的天然对照**。kimi 自写示例全对、u2 自写示例含 1 条字形误拆，二者 `self` 相对 `program` 的表现恰好分叉（持平 vs −16.7 pp），把「示例推理的正确性」与「示例来源的自我性」分离开来。

### 1.4 一个必须前置声明的边界

本文**不报告模型能力排名**。第 3.3 节用自身数据说明：现成的 100 题切片与公开数据集的完整分布均不具备排名效度（11 个答案字、85 题来自公开 train/valid、test 15 题答案全为「旦」、四家推理预算不对等）。因此下文所有百分比只用于**同一批题目上的条件间配对比较**，绝不用于跨模型优劣宣称。数据集审计在本文中被降级为方法学证据与局限，其作用是**否决 C3/C4**，而非构成本文主线。

## 2 相关工作

**汉字字谜数据集与任务。** Xu、Zhang 与 Wan（2022，2023 修订）发布 CC-Riddle，以网络爬取 + 生成模型 + 人工过滤构建，覆盖大部分常用简化字，并用检索式、生成式与多选式三种问答策略测试 BERT、ChatGPT、ChatGLM，发现现有模型难以解字谜。该数据集是当前工作的数据底座；其公开 train/valid/test 划分与「按答案字聚集」的排列方式，是本文第 3.3 节效度审计的对象。

**探针方法论、控制任务与选择性。** Hewitt & Manning（2019）提出 structural probe，检验句法树是否嵌入词表示空间的线性变换；Hewitt & Liang（2019）随即指出高探针准确率可能来自探针自身记忆了词型，主张用随机标签的 control task 度量 selectivity；Belinkov（2022）进一步综述了基线、度量、分类器选择与「相关性不等于因果」等方法论问题。这些工作都以**内部表征**为对象。本文把同一套要求迁移到**行为层**：把「同一批题、同一判分器、只换一个条件」当作控制任务，把「生成方 × 评估方」的 2×2 交叉当作选择性的识别策略，把 ICL 四条件当作对格式效应的显式控制。据我们所知，这是首次把 control-task 逻辑用于汉字结构化操作的行为诊断。

**谜题作为推理诊断工具。** Halder et al.（2025）的 RiddleBench 收录 1,737 道英文谜题，发现即使强模型也仅略高于 60%，并报告幻觉级联、错误固着、自我确认偏差（self-confirmation bias）以及约束重排下的脆弱性。与本文最接近的是「自我确认」这一发现，但 RiddleBench 的判分依赖推理链评估与模型自评，本文则在单字精确匹配上量化同类现象，并通过 2×2 设计把它与猜题能力分离。

**记忆污染与「推理还是记忆」。** Hu et al.（2026）以语言学家新创的中文歇后语构造无污染集，用低频既有项与新创项的准确率差 Δacc 作为记忆指标，发现中文前沿模型平均下降 23.6 pp 而英语中心模型仅 5.1 pp，并观察到「模型创作质量显著低于人类」。本文与该工作在「需要无污染题集」上结论一致，但诊断路径不同：我们不依赖「新造题 vs 旧题」的难度匹配，而是**让模型自己造题、再由自己在全新会话中作答**，从而在同一批题上实现配对控制；此外本文把生成侧与求解侧同时纳入观察。

**自我偏好与 LLM-as-judge。** Zheng et al.（2023）在 MT-Bench / Chatbot Arena 上系统记录了位置偏差、冗长偏差与 self-enhancement bias，并谨慎指出数据不足以断定该偏差存在。此后大量工作沿主观评分或偏好对扩展这一方向。本文的差异点在于：不存在评判者、不存在偏好对、不存在量规，只有一个可与标准答案比对的单字输出；因此观测到的 +5.22 pp 是**求解成功率之差**，不是评分倾向之差。

**上下文学习与程序性知识。** Brown et al.（2020）确立 few-shot 上下文学习，Wei et al.（2022）表明链式推理示例可激发多步推理。本文沿用 knowing-that / knowing-how 的经典区分（Ryle, 1949）来表述核心现象：模型能**描述**「木 + 目 = 相」，未必能在只有谜面时**执行**反向搜索。ICL 在此被用作**控制任务兼无需改权重的虚拟训练**，其增益方向用于区分「格式对齐缺口」与「权重层能力缺口」（第 6.4 节）。

## 3 判据驱动的研究设计与数据基础

### 3.1 三套探针总览

**表 2　本文三套实验、识别逻辑与所检验的判据**

| 探针 | 数据规模 | 操纵变量 | 识别目标 | 判据 | 主要统计 |
|---|---|---|---|---|---|
| P0 零样本解谜基线 | 100 题（四模型前置评测）+ 597 题（交叉盲测） | 无 | 基线可解性、手法难度、效度审计 | C1 C2 C3 | Wilson 95% CI、分层率 |
| P1 生成–求解闭环 | 597 题 × 2 条件 = 1,194 次作答 | 猜题方 = 对方 / 本人；会话全新 | 自我熟悉净效应、生成–理解不对称 | C2 C3 C4 C5 | 逐题配对 McNemar、2×2 可加分解、Fisher |
| P2 ICL 控制任务 | 24 题 × 4 条件 × 2 模型 = 192 次调用 | `assistant` 推理内容来源 | 能力可激活性、监督信号质量 | C4 C5 | 配对 McNemar、方向性对照 |

三套探针共用同一套系统提示、用户模板、输出解析与判分器（`riddle_eval_hy4` 的 `SYSTEM_PROMPT` / `USER_TEMPLATE` / `parse_response` / `normalize_gold`），判分统一为**去空白后的单字精确匹配**。这保证跨实验的数字可比，也是本文能把 P1 的 `cross` 条件与 P2 的 `zero` 条件直接对照的前提。需说明 P1 的 `cross` 条件即复用 P0 的 597 次交叉盲测作答，并非另跑一批；P1 新增的是 597 次 `self` 作答。

### 3.2 模型与调用协议

参与闭环实验的是两个可用的中文商用 API：**kimi-k3.1-pro**（下文记作 K）与 **u2-flash**（记作 U）。另有 **hy4** 与 **deepseek-v4-pro**（DS）参与了 11-04 的 100 题前置评测与 11-05 的 120 题高档位标定，但因账户额度返回 HTTP 402，**未参与** P1/P2 的任何调用。本文不因此推断这两家模型的能力。

关键调用协议：

- **全新单轮对话**：P1 自测的每条谜题各占一次独立 API 调用，`messages` 恰为 `[system, 单条 user]`，`history_messages=0`，不携带谜底、字理卡、出题推理、跨字示例或任何前序轮次；出题在 2026-11-05 的独立进程，答题在 2026-11-06 的新进程。凭证字段 `conversation.mode="fresh_single_turn"` 全库唯一，`maker==guesser` 对 597/597 成立。
- **提示词与采样参数**：同一 `prompt_version`（`riddle-gen-skill-v0.2-full100`），3 并发、指数退避处理 429/超时、单题超时 180 s、重试 2 次；P1 的 `self` 与 `cross` 条件的提示词、判分器、请求参数完全一致，**唯一变量是猜题方身份**。
- **零失败**：交叉盲测 597 条与自测 597 条均 `format_bad=0`、`error=0`；ICL 192 次调用同样零失败零格式异常。
- **凭据卫生**：四家 API Key 仅在运行时由统一配置读取，不进入任何产物文件；全部交付物经泄露校验。

### 3.3 数据源与效度前置审计：C3/C4 在公开切片上被否决

### 3.4 自建题集：制谜协议与质检

1. **目标字**：按现代汉语高频序取 100 个单字（含部分独体字与 IDS 占位符情形，故 IDS 不作为权威字理）。

   > **公开版口径注（2026-11-09）**：上述 1,050 / 1,023 为**构建期**完整参考集的数字，本文所有统计均以此为准。31 条网络谜面在采集时标注「网络 UGC 转载，未取得明确授权；仅本地/受限研究使用」，配套数据集 **CCRP DataSet v0.1** 按方案 C 在导出发布包时将其与绑定的 27 条站点解析、4 条 LLM 解释、58 处网页链接一并下架，仅保留 SHA256 指纹；因此发布包的 `data/reference-slice.jsonl` 为 1,019 条、`data/explanations-llm.jsonl` 为 1,019 条。本地研究产物一条未删，指纹清单见 `data/WITHHELD.md`。这一差异**不影响任何实验结论**：600 条创作题、597 条闭环题与 192 次 ICL 调用经核验不含下架谜面文本。

### 3.5 统计方法

- **区间估计**：二项比例的 Wilson 95% 置信区间（Wilson, 1927）。
- **配对比较**：同一 `gid` 两种条件的 0/1 结果构成配对四格，采用不一致格上的**精确二项检验**（McNemar, 1947 的双侧精确版本），而非正态近似。
- **组间构成比较**：2×2 列联表采用 Fisher 精确检验（Fisher, 1922）。
- **效应分解**：第 4.4 节的可加模型及恒等式推导见附录 B。
- **显著性口径**：本报告全部 *p* 为双侧；不做事后多重比较校正，因此分层结果（尤其小样本 ICL 分层）只作方向性解读。所有原始逐题结果以 JSONL 留存，可复算。

## 4 实验一：生成–求解闭环

### 4.1 设计与判据对应

597 条通过质检的自创谜题，在两个条件下各答一次：

- **交叉盲测（cross，2026-11-05）**：K 出题由 U 猜，U 出题由 K 猜。
- **同题自测（self，2026-11-06）**：K 出题由 K 猜，U 出题由 U 猜；全新单轮对话，间隔一天，不带任何出题期上下文。

两条件共用提示词、判分器、并发策略与题集；`gid` 集合完全一致，构成 597 对**逐题配对**观测。设计意图是让「题目难度」在配对比较中被自动抵消，从而把差值归因于猜题方身份的变化。对探针判据而言，该设计同时操作了 C3（信息条件的隔离）与 C5（生成/求解两个方向的对照），第 4.4 节的 2×2 分解则承担 C4 的选择性识别。

### 4.2 总体结果

**表 6　交叉盲测与同题自测总体**

| 条件 | 正确 / 总数 | 猜中率 | Wilson 95% CI |
|---|---|---|---|
| 交叉盲测（A 出题 → B 猜） | 233 / 597 | 39.03% | [35.20%, 43.00%] |
| 同题自测（A 出题 → A 猜） | 264 / 597 | **44.22%** | [40.29%, 48.23%] |
| 差值 | +31 | **+5.19 pp** | 相对提升 13.3% |

**表 7　逐题配对四格（n=597）**

| | 自测对 | 自测错 | 合计 |
|---|---|---|---|
| **交叉对** | 173 | 60 | 233 |
| **交叉错** | 91 | 273 | 364 |
| **合计** | 264 | 333 | 597 |

不一致格为 60（仅交叉对）与 91（仅自测对），精确二项检验 *p*=0.0144，在 α=0.05 下显著。两次作答的对/错一致率为 74.71%；给出**同一个答案字**的比例仅 36.35%（217/597，含都答错的同一个错字）。条件率上，`P(自测对 | 交叉对)=74.25%`，`P(自测对 | 交叉错)=25.00%`。

在解读前必须排除两种平凡解释。**其一，记住谜底**：自测是相隔一天、不同进程的全新会话，`messages` 中不含谜底与出题推理，`maker==guesser` 但 `history_messages=0`，因此答对不是从上下文复制答案。**其二，题目信息不足**：出题时模型持有目标字、IDS 卡、4 条跨字示例与指定手法，谜面正是它自己据此写出的；猜题时只缺这些信息，谜面本身完整。故两条件的差别只能来自「求解者是谁」（以及随之而来的内部表征差异）。权重层面的自我熟悉（同一模型既出题又答题）无法被完全排除，这是本文的重要局限，第 7 节详述。

### 4.3 分层结果：一个表观矛盾

**表 8　按制谜方与手法分层**

| 分层 | n | 交叉 | 自测 | 差值 | McNemar *p* |
|---|---|---|---|---|---|
| K 出题 | 298 | 36.58% | 58.05% | **+21.48 pp** | < 0.0001 |
| U 出题 | 299 | 41.47% | 30.43% | **−11.04 pp** | 0.000142 |
| 拆形 | 197 | 49.75% | 60.41% | +10.66 pp | **0.0139** |
| 会意 | 200 | 35.00% | 37.00% | +2.00 pp | 0.665 |
| 谐音 | 200 | 32.50% | 35.50% | +3.00 pp | 0.405 |

按制谜方分层，两家方向完全相反且都显著；若草率解读，会得出「只有 K 认得自己的谜、U 反而更不认得」这种随模型而异的结论。按手法分层，则只有**拆形**的自测增益显著（+10.66 pp），会意与谐音均不显著；最突出的单格是 K 自猜拆形谜 48.98% → 84.69%（+35.71 pp）。手法给出了稳定且可解释的难度序（拆形 > 会意 ≈ 谐音），这是 C2 成立的直接证据。

### 4.4 2×2 全因子分解：方向相反是混淆，不是矛盾

关键在于：**按制谜方分层时，猜题方也被同时换掉了**。K 出题时，自测意味着强猜手 K、交叉意味着弱猜手 U；U 出题时恰好倒过来。把两天的四个格子摊开，恰好构成一个近似完整的 2×2 全因子（制谜方 ∈ {K, U} × 猜题方 ∈ {K, U}）：

**表 9　制谜方 × 猜题方四格（猜中率）**

| 制谜方 \ 猜题方 | K 猜 | U 猜 |
|---|---|---|
| **K 出题** (n=298) | 58.05%（自测） | 36.58%（交叉） |
| **U 出题** (n=299) | 41.47%（交叉） | 30.43%（自测） |

设可加模型（推导见附录 B）：

`rate = μ + α·1[题源=K] + β·1[猜题方=K] + γ·1[制谜方 = 猜题方]`

由四格解得：*μ*=0.252149（U 出题 U 猜基线扣除 γ 后）、*α*=+0.113623（K 出题的题源更易猜）、*β*=+0.162566（K 的猜题能力高出 U 16.26 pp）、**γ=+0.052199（自我熟悉净优势 5.22 pp）**。以上均以原始计数之比计算、不预先舍入，推导见附录 B。

于是两个分层差值被完全解释：

- K 出题：自测 − 交叉 = (强猜手 + 自我) − (弱猜手) = *β* + *γ* = +21.48 pp ✓
- U 出题：自测 − 交叉 = (弱猜手 + 自我) − (强猜手) = −*β* + *γ* = −11.04 pp ✓

即**两家模型共享同一个约 +5.2 pp 的自我优势**，符号被 ±16.3 pp 的猜题能力差翻转。更重要的是恒等式：在平衡设计下，总体「自测 − 交叉」差值严格等于 *γ*；本实验两组 n=298/299 略有不平衡，故实测总体差值 +5.19 pp 与 *γ*=+5.22 pp 相差 0.03 pp，来自组大小与四舍五入。这意味着**第 4.2 节的总体显著性检验，检验的正是 γ 本身**，而非被主效应污染的混合物。

> **分解的边界（必须随结论一起报告）**：这是描述性可加分解，不是回归估计；两组题源不同（K 298 条 / U 299 条），并非同一批题的严格重复测量；依赖「效应可加、无高阶交互」假设；未给出 *γ* 的置信区间。若 K 与 U 的自我优势强度实际不等（存在交互），*γ* 应读作两者的加权平均净效应。

从探针方法论看，这一节是 C4 的核心：**若未把「生成方」与「评估方」作为两个独立因子交叉，任何「A 生成 → A 评估」型探针的读数都会被评估能力主效应污染**。这正是 Hewitt & Liang（2019）所要求的选择性检验在行为层的对应物。

### 4.5 四格诊断：答对与答错各说明什么

把交叉/自测四格与手法、制谜方交叉，得到本文最核心的诊断材料：

**表 10　作答四格 × 手法 × 制谜方**

| 四格 | n | 拆形 / 会意 / 谐音 | K 出题 / U 出题 |
|---|---|---|---|
| 都对 | 173 | 75 / 48 / 50 | 102 / 71 |
| **仅自测对** | 91 | 44 / 26 / 21 | **71 / 20** |
| **仅交叉对** | 60 | 23 / 22 / 15 | **7 / 53** |
| 都错 | 273 | 55 / 104 / 114 | 118 / 155 |

制谜方归属在「仅自测对」与「仅交叉对」两格间的差异极显著（K:U = 71:20 vs 7:53，Fisher *p*=1.65×10⁻¹²）：强模型出的题自己解得出，弱模型出的题反而别人更解得出。

**答对（尤其 91 条「只有自己解得出」）说明什么。** 出题期的输入是（目标字 + IDS 卡 + 4 条跨字示例 + 指定手法），答题期只剩谜面。谜面中编码的线索能被同一模型沿生成路径**逆向还原**为求解路径，说明生成策略与求解策略共享一套内部程序或风格约定，而非靠记忆。两个典型案例：

- 「衣裳同音，数数它最先」→ 谜底「一」：U 答「衣」，K 自答「一」（谐音指向的约定被出题者自己沿用）。
- 「卜字脚下添一横」→ 谜底「上」：U 答「下」，K 自答「上」（方位解释只在同一模型的生成/求解约定内自洽）。

**答错（尤其 60 条「别人能解自己解不出」与 273 条都错）说明什么。** 模型在有答案、有字理卡、有示例时能写出一段看似合理的解谜叙述；把这些信息撤走后，同一个模型却解不回自己刚造的谜。这提示那段叙述未必是**可执行的求解程序**，而更接近**给定答案后的叙述化**。典型案例：

- 「叉去一点，添上一寸」→ 谜底「对」：U 答对，出题的 K 自答「夺」。
- 「九百六十万平方公里」→ 谜底「国」：U 答「国」，K 自答「垚」——自家先验反而把自己带偏。

**手法层面**：273 条都错中，会意 + 谐音占 218/273 = **79.85%**，显著高于总体的 400/597 = 67.00%。开放式语义/语音联想是两家模型的共同盲区，而结构化拆形相对可迁移。

### 4.6 两处必须报告的负面结果

为避免把上述解释写成过度确定的结论，我们额外做了两项检验，结果**不支持**强解释：

**表 11　负面结果检验**

| 检验 | 数值 | Fisher *p* | 判定 |
|---|---|---|---|
| 「仅自测对」vs「仅交叉对」的拆形占比 | 44/91 (48.4%) vs 23/60 (38.3%) | **0.245** | 不显著。可说的只是「总体增益按手法分解时拆形显著（表 8）」，**不能**说「自我优势集中在拆形」——两句话不是一回事 |
| 出题推理文本中直接出现谜底字的比例（至少一方解出 vs 都错） | 293/324 (90.43%) vs 258/273 (94.51%) | **0.066** | 仅为趋势；且方向是「都错组含谜底字更多」，不能作为「reasoning 是事后合理化」的硬证据 |

因此本文对 RQ1 的回答是**有限度的**：数据支持「生成–求解之间存在程序性不对称」，且这一不对称的方向可由「是否持有答案」预测；但「出题期 reasoning 纯属事后编造」这一强命题，在本数据中未被证实，需依靠第 5 节 ICL 的错误示例实验从另一角度提供证据。对 C5 而言，这一节只能给出间接证据。

## 5 实验二：ICL 控制任务

### 5.1 设计：控制任务与虚拟训练的双重角色

P1 显示缺口位于「只给谜面时的逆向执行」。RQ3 追问：不改动权重、仅在上下文里给解谜示例，能否激活该能力？若能，说明权重里已有能力、缺的只是任务格式对齐；若不能，则更可能需要权重层的结构表征注入。就探针判据而言，这一节同时承担两个角色：作为**控制任务**检验 C4（把格式效应、示例来源与推理正确性分开），作为**无需改权重的虚拟训练**为 C5 提供方向性证据。

**题集**：从 597 题按 (制谜方 × 手法) 分层抽 24 题（K/U × 拆形/会意/谐音，每格 4 题），固定种子 20261106，题集 SHA256 `b16111d9…8537f` 冻结。**示例字 {对, 但, 和, 学} 与 24 个测试字严格不相交**，沿用留出隔离纪律，杜绝示例直接泄露谜底。

**四条件**（`zero` / `answer` / `program` / `self`）：后三者**共用完全相同的 4 条谜面与谜底**（2 拆形 / 1 会意 / 1 谐音，均取自 K 的创作），唯一差别是 `assistant` 回复中的推理内容：

**表 12　ICL 四条件**

| 条件 | k | `assistant.reasoning` 内容 | 平均 prompt token |
|---|---|---|---|
| `zero` | 0 | 无示例（同批基线） | 279.0 |
| `answer` | 4 | 空（仅谜面 → 谜底），控消息结构与长度 | 538.0 |
| `program` | 4 | 人工编写的**可执行**拆解步骤 | 712.5 |
| `self` | 4 | **该模型自己**在给定谜底后写的事后解释 | 739.5 |

`program` 与 `self` 的谜面、答案、消息结构、系统提示、采样参数完全相同，prompt 长度 712.5 vs 739.5 token，长度差异仅来自推理文本本身——这是整套实验中**最干净的对照**：唯一实质变量是「推理内容由谁写、写得对不对」。

示例谜面举例（拆形）：「旭日初升人独立」→ **但**。人工程序推理为：「旭日初升」给出「日」与地平线一横，上下叠成「旦」；「人独立」取单人旁「亻」；左右并置得「但」。

### 5.2 结果

192 次调用（2 模型 × 24 题 × 4 条件），零失败、零格式异常，累计请求耗时 1,983.1 s（3 并发，墙钟约 11 分钟），输入 108,912 token、输出 61,720 token。

**表 13　ICL 主结果（正确数 / 24，猜中率）**

| 模型 | `zero` | `answer` | `program` | `self` |
|---|---|---|---|---|
| kimi-k3.1-pro | 10/24 (41.67%) | 10/24 (41.67%) | 11/24 (**45.83%**) | 11/24 (**45.83%**) |
| u2-flash | 9/24 (37.50%) | 7/24 (29.17%) | 9/24 (37.50%) | 5/24 (**20.83%**) |

**没有任何一个条件与 `zero` 的差异达到显著**（最小 *p*=0.125，n=24 每格仅 8 题）。按手法分层后，`program − answer` 的增益散落在拆形与谐音（三格 +12.5 pp：K×谐音、U×拆形、U×谐音），而**会意题在 `zero`/`answer`/`program` 三个条件下完全不动**（K 会意恒为 25.0%，U 会意恒 ≤12.5%），仅 K 的 `self` 条件有 1 题波动（25.0%→37.5%，不显著）。

**预测 P1「增益集中在拆形」未获验证**；但换一个读法更有价值：会意题在四个条件下几乎纹丝不动，说明开放式语义联想不是 few-shot 能激活的能力。

### 5.3 天然对照：一条错误解释如何拖垮整个条件

`prepare` 阶段出现了一个非设计使然、却极具解释力的对照：K 与 U 各自为 4 条示例谜面写事后解释时，**K 的 4 条全部正确**，而 **U 的「旭日初升人独立」一条写错了字形拆解**：

> U 的自写解释：「谜面『旭日初升』取『旭』字去掉『日』（初升的太阳），剩『九』；『人独立』表示『人』字独立站立，可变形为『亻』。『九』与『亻』组合，即为『但』字。」
>
> 正确的程序：「日 + 一 = 旦」；「亻 + 旦 = 但」。
>
> K 的自写解释：「『旭日初升』会意为『旦』，即太阳从地平线上升起；『人独立』提示单立人『亻』。将『亻』与『旦』左右组合，便成谜底『但』。」（正确）

于是两家 `self` 条件相对 `program` 的表现恰好分叉：

**表 14　关键直接对照（配对四格）**

| 模型 | 对照 | 仅 A 对 | 仅 B 对 | 都对 | 都错 | McNemar *p* |
|---|---|---|---|---|---|---|
| kimi | `program` vs `self` | 1 | 1 | 10 | 12 | 1.000 |
| kimi | `program` vs `answer` | 1 | 0 | 10 | 13 | 1.000 |
| u2 | **`program` vs `self`** | **4** | **0** | 5 | 15 | **0.125** |
| u2 | `program` vs `answer` | 4 | 2 | 5 | 13 | 0.6875 |

K 的 `self` 与 `program` 完全持平（45.83%），U 的 `self` 掉到 20.83%——比 `zero` 低 16.67 pp，比 `program` 低 16.67 pp，`program` 对 `self` 为 4:0 的单向优势。由于两条件除推理文本外完全相同，最简解释是：**示例里那条错误的字形拆解被模型当作可复用的程序学进去了**，而不是「自己的解释天然更亲和」。附带一个反直觉观察：仅给 (谜面, 谜底) 的 `answer` 对 U 是干扰（29.17%），加上程序脚手架才回到 37.50%。

**这条证据同时补上了第 4.6 节留下的缺口**：4.5 节只能说「给定答案后的叙述未必可执行」，Fisher *p*=0.066 不足以证实；而本节表明，一旦把这类叙述作为上下文示范，其中的错误会**直接转化为求解错误**。它支持「事后解释不宜默认为监督信号」的推论，但请注意，这仍是**单次、单条错误示例**的观察，且 *p*=0.125 不显著。就 C5 而言，这属于方向性证据而非判定性证据。

### 5.4 复现性：日间漂移比预期更小

为量化单次采样噪声（C6），我们把 ICL 的 `zero` 条件与 11-06 自测中**严格同模型同题**的 12 题比对（早期版本曾误把 11-06 中由另一模型作答的题也纳入对比，已修正口径）：

| 模型 | n | 判定一致 | 一致率 | `zero` | 11-06 自测 |
|---|---|---|---|---|---|
| kimi | 12 | 12 | **100%** | 33.33% | 33.33% |
| u2 | 12 | 9 | 75% | 33.33% | 25.00% |

K 隔一天完全复现，U 有三题翻转。这说明本实验的采样波动小于常见担忧，P1 的 597 条配对结果具有较好的重测稳定性；但 n=12 仍不足以给出紧的方差估计，第 7 节仍把「单次采样」列为局限。

### 5.5 三个可证伪预测的判定

**表 15　实验前预测与判定**

| 预测 | 判定 | 说明 |
|---|---|---|
| P1 程序示例的增益集中在拆形 | **未验证** | 增益散在拆形/谐音；但会意在 `zero`/`answer`/`program` 三条件下零增益，可作为「开放式联想难以由 few-shot 激活」的方向性证据 |

## 6 综合裁定：字谜能否成为结构探针

### 6.1 判据逐条裁定

把第 3–5 节的证据按表 1 的六条判据归拢，得到对题目的直接回答：

**表 16　六条判据的逐条裁定**

| 判据 | 关键证据 | 裁定 |
|---|---|---|
| C1 客观可判分 | 单字精确匹配；1,194 次闭环作答 + 192 次 ICL 零格式异常；无评判者、无偏好对、无量规 | **满足** |
| C2 结构化可分解 | 三手法给出稳定难度序（49.75% / 35.00% / 32.50%）；都错格 79.85% 为会意+谐音；生成/求解两方向可分别操纵 | **满足** |
| C3 信息条件可控 | 自建 597 题：出题期持字理卡与答案，答题期仅谜面、隔一天、全新单轮；但公开 100 题切片仅 11 个答案字、85/100 来自 train/valid、test 15 题全为「旦」 | **分场景**：自建题集满足，公开切片不满足 |
| C4 选择性 | 2×2 全因子把 *β*=+16.26 pp 从分层差值中分离，剩 *γ*=+5.22 pp；ICL 同谜面仅换推理来源（712.5 vs 739.5 token）。但四家推理预算不对等、无人类基线、无多次采样 | **部分满足**：题内对照充分，跨模型对照不足 |
| C5 能力层可区分 | ICL 192 次调用，`program` vs `self` 4:0、会意题三条件零增益；但所有 McNemar *p*≥0.125 | **未达标**（仅方向性信号） |
| C6 可复现可审计 | seed 20261106 + SHA256 冻结、prompt 版本固定、逐题 JSONL 留存、三级溯源与 `no_url` 标记；日间复现 K 100% / U 75% | **满足** |

因此答案不是二值的。**C1/C2/C6 三条「资格判据」全部满足**，这在中文能力诊断任务中并不常见：多数任务要么依赖主观评分（C1），要么只有一个总分（C2），要么无法逐题复算（C6）。**C3/C4 是分水岭**：一旦换成自建、配对、可交叉的题集，字谜的读数可以归因；沿用公开切片则不能。**C5 是当前唯一硬缺口**，它决定了探针能否外推到训练。

> **一个额外的元发现**：探针本身也会被「自我熟悉」污染。+5.22 pp 的 *γ* 意味着，任何「模型自己生成题目 → 自己或同系列模型评估」的探针设计，若未交叉生成方与评估方，读数里都会混入这一净优势。这可以看作对 control-task 方法论在生成式评测场景下的一个具体补充。

### 6.2 三种用法，三种结论

「能否成为结构探针」还取决于「拿来做什么」。同一批数据在不同用法下裁定不同：

**表 17　三种用法的裁定**

| 用法 | 读数的含义 | 裁定 | 依据 |
|---|---|---|---|
| 诊断型结构探针 | 同一批题、同一判分器下的**条件间配对差** | **能** | C1/C2/C6 满足，C3/C4 在自建闭环题集内满足；照出三类能力缺口与一个可分离的偏差 |
| 排名型基准 | 跨模型总体准确率 | **不能**（现有切片） | 表 3 / 表 4：11 个答案字、记忆污染、推理预算不对等；四家在 15 题 test 上 6/5/6/7 持平 |
| 训练信号探针 | SFT / 数据构造的因果效应 | **尚不能判定** | 无任何训练实验；ICL 只是无需改权重的替代观察，且全部 *p*≥0.125 |

三者不可互相替代：把诊断型探针的配对差当作排名，或把 ICL 的方向性信号当作训练有效性结论，都是对读数的误用。

### 6.3 探针照出的能力结构

**汉字结构知识是「可描述但不可执行」的。** CC-Riddle 原论文已指出模型在字谜任务上表现不佳。本文从生成–求解闭环给出互补证据：模型**能谈论**「木 + 目 = 相」这类结构关系，甚至在持有答案与 IDS 卡时写出完整的解谜叙述；但当输入收缩为一句谜面时，同一模型无法稳定执行反向搜索。用 knowing-that / knowing-how 的区分（Ryle, 1949）表述，观察到的是**陈述性描述与程序性执行之间的断裂**，而非单纯的「不知道字形」。三个观测共同指向这一点：① 597 条中 273 条两家都错（45.7%）；② 60 条「别人能解、出题者自己解不出」；③ 出题推理含谜底字的比例与可解性的关系 *p*=0.066、方向甚至相反。必须克制的是：我们没有做推理链的人工逐条标注，无法给出「多少比例的 reasoning 是伪程序」这类定量结论。

**自我偏好可以在客观判分任务上被量化并分离。** 已有 self-preference 研究多建立在主观打分、偏好对或自评之上，评判工具本身携带偏差。本文把评判环节完全去掉，仍观测到 +5.22 pp 的净自我优势（配对 *p*=0.0144），说明该现象不是 LLM-as-judge 的度量伪影。方法上更值得强调的是识别策略：如果只按制谜方分层，会得到「K +21.5 pp、U −11.0 pp」这一看似随模型而异、难以解释的读数；把制谜方 × 猜题方做成 2×2 全因子后，表观矛盾被 *β*=+16.26 pp 完全解释，剩下共同的 *γ*=+5.22 pp。

**手法分层：结构化可迁移，开放式是共同盲区。** 三层结果一致：交叉盲测中拆形 49.75% > 会意 35.00% > 谐音 32.50%；总体自测增益按手法分解只有拆形显著（+10.66 pp, *p*=0.0139）；都错格中会意+谐音占 79.85%（总体 67.00%）；ICL 中会意在 `zero`/`answer`/`program` 三条件下完全不动。合起来可读作：**依赖离散字形操作的线索相对容易被形式化、也相对容易跨模型迁移；依赖语义别解、文化常识与声调联想的线索是两家模型的共同地板**。这与 CC-Riddle 原论文强调「字谜需要字形、常识与比喻语言的综合」一致，并进一步指出三者的难度并不对等。同样要克制：第 4.6 节已说明「自我优势集中在拆形」在四格占比层面不成立（Fisher *p*=0.245）。

### 6.4 对训练数据设计的含义：三条可证伪假设（**非实证结论**）

本课题最初的问题之一是「这类数据对训练有什么价值」。**本文没有做任何 SFT、消融、训练曲线或下游迁移实验，因此不给出任何训练有效性结论，也不认为 C5 已达标。** 但把前述三类实证并置，可以把「训练价值」改写为**带观测锚点的假设**，并明确其证伪条件：

**表 18　由观测支撑的训练假设与证伪路径**

| # | 观测锚点 | 假设 | 证伪条件 |
|---|---|---|---|
| H1 监督信号必须是可执行且经校验的步骤 | ICL 中 1 条错误自解释使 U 掉 16.7 pp（`program` vs `self` 4:0）；1,023 条事后解释 58.9% 自评 low | 用 `(谜面, 事后解释, 谜底)` 做 SFT 会教模型编理由；应改用 `(谜面, 可执行拆解, 谜底)`，且拆解须能被程序或人工校验 | 若用校验后的步骤训练与用未校验解释训练，在留出集上无差异，H1 被证伪 |
| H2 仅 `(谜面, 谜底)` 对弱模型可能有害 | U 的 `answer` 条件 29.17% < `zero` 37.50%，补上程序脚手架才回到 37.50% | 弱模型需要过程监督而非纯标签监督；纯标签对齐可能挤占本已脆弱的求解路径 | 若扩大到 120 题后 `answer` 与 `zero` 无差异或反超，H2 被证伪 |
| H3 会意/谐音缺口可能不在格式层 | 会意题在程序示例条件下零增益；都错格 79.85% 为会意+谐音 | 这部分能力更可能需要权重层注入（结构/音韵表征、别解训练数据），few-shot 无法激活 | 若在 k=2/4/8 梯度、含高质量会意程序示例下出现显著增益，H3 被削弱 |

此外有三条**训练/评测数据构造层面的风险**，均有本数据实证支撑，可作为协议建议而非效果宣称：

1. **泄漏风险**：试点网络素材 84.2%（16/19）与 CC-Riddle 转载链完全一致、合并集另有 12/43 直接重复，且公开 split 未按答案字隔离（test 15 题答案全为「旦」）。用这类语料扩充训练集并沿用原 split 评测，会同时引入记忆污染与分布泄漏。
2. **监督信号风险**：给定谜面 + 谜底补写的解释本质是事后合理化（58.9% 自评 low，手法自动分类偏会意 594:427:2）。把它当 CoT 监督，等于优化「叙述的合理性」而非「求解的可执行性」。
3. **合成数据反馈循环**：自出题自答存在 +5.22 pp 净自我优势。若用某模型生成题目/解释，再让同系列模型自评或自测，会系统性高估其能力；评测协议应强制生成方与评估方交叉（见 4.4 与 6.1）。

对「ICL 提得动 / 提不动」的判读规则也在此明确：**提得动** ⇒ 权重里已有能力，训练只需任务格式对齐；**提不动** ⇒ 更可能需要权重层注入，且训练数据须是可执行步骤。本文 24 题探针**尚不足以判定属于哪一种**（所有 *p*≥0.125），因此 H1–H3 全部保留为待检验假设。

### 6.5 让字谜成为更好探针的协议建议

针对未达标的判据，补齐路径如下：

1. **补 C3**：重建题集时按答案字分层、固定种子、SHA256 冻结，并从 `split=test` 的 3,831 条人工题中取；不要把按 id 顺序的前 N 批当随机样本（表 3）。冻结 1000 条分层 test 集是当前最高优先级的下一步。
2. **补 C4（跨模型）**：把「是否开启原生思考」作为独立实验变量单独报告，或至少并列标注耗时与思考 token；四家「最高档」语义不同，直接比较会重新引入 11-04 的预算不对等。并补人类基线与多次重复采样。
3. **补 C4（设计）**：生成–评估型实验必须交叉生成方与评估方两个因子，并报告配对不一致格与精确检验，而非只给总体准确率。
4. **补 C5**：把 ICL 矩阵扩到 120 题（4 类示例 × k=0/2/4）以给出有意义的 *p* 值，并补人工对「解谜叙述是否可执行」的逐条标注；若条件允许，再做真实 SFT 消融。
5. **保持 C1/C6**：继续报告负面结果与所有分层，避免只展示显著子组（表 11、表 15 即为示范）；溯源分级为数据集来源给论文/仓库 + 行 id + 文件哈希、网页来源给链接 + 片段哈希、模型生成内容标记 `no_url`，**绝不伪造 URL**。

## 7 局限

**实验规模与显著性。** ICL 探针仅 24 题、每手法每格 8 题、单次采样，192 次调用中所有 McNemar *p*≥0.125，第 5.3 节的核心对照也只是方向性信号；这正是 C5 未达标的直接原因。要给出有意义的 *p* 值，需扩到 120 题完整矩阵（4 类示例 × k=0/2/4）。第 4 节的 597 条配对是本文唯一达到统计显著的结果。

**模型覆盖。** 闭环实验只有 K 与 U 两个中文商用 API；hy4 与 DS 因 HTTP 402 额度耗尽未参与（标定集中两家分别有 55/120、53/120 条异常）。无开源模型、无海外模型、无人类基线、无多次重复采样。因此本文不主张任何跨厂商或跨语种的普遍性，C4 的跨模型部分也因此只能判为「部分满足」。

**设计层面。** ① 2×2 分解为描述性可加模型，两组题源不同（298/299）非严格配对，依赖无交互假设，未估 *γ* 的置信区间；② 权重层面的自我熟悉无法排除——同一模型既出题又答题，「全新对话」只清除了上下文，未清除权重；③ 示例谜面全部取自 K 的创作，可能对 K 存在风格优势；④ `zero` 与 few-shot 的消息轮数不同（ICL 固有），`answer` 条件仅部分控制；⑤ 人工程序示例只有 4 条、无 k 梯度；⑥ 两次实验相隔一天，模型版本可能变化；⑦ 出题期未采集人工对「解谜叙述是否可执行」的逐条标注。

**题集层面。** ① 597 题覆盖 100 个高频字，不含低频字与繁体；② 全部为 zero-shot 解谜，制谜阶段用的 4 条跨字示例不进入答题；③ 质检以自动规则 + 3-gram Jaccard 原创性阈值（0.35，由 60 条试点标定）为主，**未做人工谜面质量与谜底唯一性评审**，这是当前最大缺口；④ 解释均为事后合理化或站点现成提示，非权威字理；⑤ 会意/谐音可能存在地板效应，压缩了 ICL 增益的可观测空间；⑥ 字义字段未按原计划补充，会意手法受限。

**术语与外推边界。** 本文的「结构探针」是行为层探针，不提供内部表征层面的证据；C1–C6 判据是为汉字结构化操作任务定制的，是否适用于其他语言或任务需另行检验。

**数据与伦理。** 本文配套数据集以「**汉字字谜探针数据集 / Chinese Character Riddle Probes Dataset（CCRP DataSet）v0.1**」于 2026-11-09 公开发布，发布者春芽数源（Spring Buds Data Source Inc.）。按目录分层许可：`data/` 为 **CC BY-NC-SA 4.0**（非商业、署名、相同方式共享，继承上游 CC-Riddle 的许可；§4(b) 数据库权使含其实质内容的数据库构成 Adapted Material），`scripts/` 为 MIT，`paper/` 与文档为 CC BY 4.0；上游三位作者的完整署名、许可链接、原库 URI 与「已做选取、重排、补解释」的修改声明见仓库 `THIRD_PARTY.md`。CC BY-NC-SA 4.0 **不是** OSI 认证的开源许可；免费公开仓库本身属 §1 定义的非商业行为，NC 约束的是下游商业使用。构建期参考集中的 31 条网络 UGC 谜面自带「仅本地/受限研究使用」标记，按方案 C 未随包发布，仅保留 SHA256 指纹（`data/WITHHELD.md`）；**本地研究产物一条未删**，离线站点与小游戏仍为本地/受限访问、不对外发布。全部公开产物经扫描不含明文凭据、不含本机绝对路径、不含第三方网页链接。本文未使用人类被试数据。

## 8 结论

**汉字字谜能成为大语言模型的结构探针，但只在特定用法与特定题集条件下成立。**

按六条有效性判据逐条检验：C1（客观可判分）、C2（结构化可分解）、C6（可复现可审计）完全满足；C3（信息条件可控）与 C4（选择性）在自建的 597 题闭环题集上成立、却被现成公开切片否决；C5（能力层可区分）目前只有方向性证据，是唯一硬缺口。因此，**作为诊断型结构探针：能**——它以单字精确匹配、三手法正交分解、生成/求解可逆闭环与 2×2 交叉控制，照出了三类能力结构：汉字结构知识「可描述但不可执行」、生成–求解不对称、以及 +5.22 pp 的自我熟悉偏差（后者若不作因子分离会被 ±16.26 pp 的猜题能力差翻转符号）；**作为排名型基准：不能**——11 个答案字、记忆污染与推理预算不对等使跨模型分数不可归因；**作为训练信号探针：尚不能判定**——ICL 控制任务虽给出「示例效果取决于推理正确性而非自我性」的干净对照，但全部 *p*≥0.125，且无任何训练实验。

由此，本文对题目给出一个可复核的裁定，同时给出使它从「有条件肯定」走向「无条件肯定」的路径：冻结 1000 条按答案字分层的 test 集（补 C3）、控制推理预算并补人类基线与多次采样（补 C4）、把 ICL 矩阵扩到 120 题并补人工推理链标注与真实 SFT 消融（补 C5）。此外，本文的方法论副产品具有超出字谜的适用性：**任何「模型生成 → 模型评估」型探针，若未把生成方与评估方作为独立因子交叉，其读数都可能被评估能力主效应与自我熟悉净效应污染**。

## 附录 B　2×2 可加分解推导

记四格观测率（表 9）。以下一律使用**原始计数之比**，不预先舍入：

- `r(K,K) = 173/298 = 0.580537`
- `r(K,U) = 109/298 = 0.365772`
- `r(U,K) = 124/299 = 0.414716`
- `r(U,U) = 91/299 = 0.304348`

模型 `rate = μ + α·1[题源=K] + β·1[猜题方=K] + γ·1[制谜方=猜题方]` 给出：

```
r(K,K) = μ + α + β + γ
r(K,U) = μ + α
r(U,K) = μ + β
r(U,U) = μ + γ
```

由后三式得 `α = r(K,U) − μ`、`β = r(U,K) − μ`、`γ = r(U,U) − μ`，代入第一式：

```
μ = [r(K,U) + r(U,K) + r(U,U) − r(K,K)] / 2
  = (0.365772 + 0.414716 + 0.304348 − 0.580537) / 2 = 0.252149
```

故 `α = 0.113623`（+11.36 pp）、`β = 0.162566`（+16.26 pp）、`γ = 0.052199`（+5.22 pp）。分层差值：

```
K 出题：r(K,K) − r(K,U) = β + γ = 0.214765 = +21.48 pp
U 出题：r(U,U) − r(U,K) = −β + γ = −0.110368 = −11.04 pp
```

两个等式在精确计数下**严格成立**（β+γ 与 −β+γ 恰等于两行差值），不存在近似。

> **口径说明**：配套分析文件 `selftest-analysis.json` 与离线站点采用「先把率四舍五入到四位小数再运算」，得 `α=0.11365`、`β=0.16255`、`γ=0.05215`、K 行差 `+21.47 pp`。两种口径最多相差 0.01 pp，不改变任何结论；本文正文统一采用精确计数口径。

**恒等式**：在每组题数相等（n_K = n_U）时，

```
总体差值 = ½[(β+γ) + (−β+γ)] = γ
```

本实验 n_K=298、n_U=299，故实测差值 +5.19 pp 与 γ=+5.22 pp 相差 0.03 pp。这说明第 4.2 节对总体差值做的 McNemar 检验，检验对象本质上就是 γ。
